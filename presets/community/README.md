# Community Spark 40 presets

119 Spark app preset files (JSON) collected from the sources below, plus
`SurfWipeout.json` (surf tone, made for this project):

- [stangreg/Ignitron](https://github.com/stangreg/Ignitron) (`data/`), BSD 3-Clause, see `LICENSE-Ignitron`
- [mpkottawa/ignitron-preset-tools-2.0](https://github.com/mpkottawa/ignitron-preset-tools-2.0) (`Ignitron/data/`)

Duplicates (same UUID) were removed.

Import them into PGSparkLite from the Settings page ("Import Chain Presets"),
or from the project root:

    python3 -m utils.import_presets presets/community
